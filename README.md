# Burak Kiliç — Portfolio

A calm, modern, dark portfolio. Geist sans across the board, a single accent color, dense information on a tight grid.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Push to GitHub and import into Vercel. No env vars required.

## Resume

Drop your PDF at `public/resume.pdf` for the download links to work.

## Stack

Next.js 14, TypeScript, pure CSS. Geist + Geist Mono.
